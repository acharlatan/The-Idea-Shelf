# The illustrated collection

The 30 square illustrations in `public/assets/ideas/` were generated as separate original images for the corresponding idea entries, then resized and encoded as WebP for the website. Each filename matches its idea ID.

Shared prompt direction: an original illustration for The Idea Shelf, a playful but polished creative inspiration library for marketers; a handcrafted miniature tabletop set in tactile paper and polymer clay; warm cream background with strawberry red, blush pink, butter yellow and gentle sage accents; soft daylight; an art-directed editorial still life; charming and sophisticated; square composition; no people, legible writing, logos, or watermarks. The first Listening Wall illustration used the same direction with a community question wall as its subject. Images were created with the built-in image generation tool.
